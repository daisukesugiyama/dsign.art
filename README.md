## しくみ

- `css/site.css` 共通。`:root` の `--band-x` `--band-w` `--shu` が「帯」。いまの作品（No.001）の朱の帯が画面の 39.6% に立つので、ページにも同じ位置に帯を立てている。ホームの作品は横幅いっぱいに置くので、作品の帯とページの帯がつながる。次の作品で位置と色を変える
- 小さい画面では、帯は紙（`.sheet`）の後ろを通り、紙と紙のすき間にだけ見える
- `js/site.js` 言語（日・英・中）とメニュー。`?lang=en` を付けたリンクで英語のページを開ける
- `js/viewer.js` 原寸ビューア（OpenSeadragon 5.0.1 を `js/vendor/` に同梱）。ミニマップは置かない（寄ると全体が分からなくなる作りのため）。目盛りは作品の cm
- 絵の下の左に「物差し」：全体から画素まで一本の線で、全体・原寸の½や¼（画面の大きさで数が変わる）・原寸・画素に目盛り。朱の短い縦線がいまの立ち位置で、寄ると動く。目盛りや言葉を押すとそこへ、両端の − ＋ で一段ずつ（端では薄くなって押せない）。原寸にいるときは「原寸」が朱の札になる。物差しが短くて「原寸」と「画素」がぶつかるときは、「原寸」を目盛りの左に寄せる
- マウスでは、クリックで一段寄る。画素の次のクリックは全体に戻るので、クリックが行き止まりにならない。ポインタは次のクリックが何をするかを示す（虫眼鏡の＋、画素では−、ドラッグ中はつかむ手）。Shift か ⌥ ＋クリックで一段引く。初めて画素まで来たときだけ、真ん中に「もう一度クリックすると、全体に戻る」。ホイールはページを動かし、Ctrl/⌘＋スクロールやトラックパッドのピンチで寄る。全画面のボタンは右端
- 指（スマホ・タブレット）では、ページの上ではページが先：1本指でなぞってもページが上下に動くだけで、作品は動かない。絵をタップするか、右上の「寄って見る」を押すか、2本指で広げると全画面になる（2本指のときは、広げた場所と寄り具合のまま開く）。指で寄って動き回るのは全画面の中だけ。右上の × か、スマホの「戻る」でページに戻る（ページの位置は変わらない）。寄りの場所（`#torso2` など）を指で開くと、全画面でその場所が原寸で開く
- ページそのものは拡大しない（`html{touch-action:pan-x pan-y}`、iOS Safari には `site.js` で gesturestart を止める）。ページは作品と同じ割り付けなので、拡大すると帯と紙がずれて、どこにいるか分からなくなるため。写真に2本指を置くと、その場で少し寄れて、離すと戻る（`data-peek`）
- 止めきれない所がひとつある：iOS Safari は、はじいたスクロールの惰性でページがまだ滑っているあいだ、指をページに渡さない（WebKit の不具合 [220457](https://bugs.webkit.org/show_bug.cgi?id=220457)）。その瞬間のピンチは CSS でも JS でも止められず、ページが拡大される（止まっているページ、上端・下端では止まる）。拡大されたら `site.js` が `visualViewport.scale` を見て `html.is-zoomed` を付け、止めるのをやめる。ピンチやダブルタップで1倍に戻せて、戻るとまた止める。拡大中は `data-peek`、ビューア（`viewer.js`）、2021–2023 の `.stage` も指をブラウザに渡す
- `js/door.js` 扉の動き。どちらの作品を出すかを決めて（`localStorage` の `dsign-door`）、動かす。動きを減らす設定の人には、はじめから全体を出す。ビューアが読めないときは、動きが止まる所と同じ場所に全体の静止画（`whole-2400.jpg`）
- `torso/001/tiles.dzi` と `tiles_files/` 原寸 10630 × 5950 px のタイル（JPEG、色の間引きなし）。`torso/001/img/` 全体の縮小、寄りの 8 か所、OG 画像
- 画像はどれも C2PA などのメタデータを持たない（書き出しで落としてある）
- `css/site.css` と `js/*.js` は、どのページでも `?v=20261023h` のような版の印を付けて読む。CSS や JS を変えたら、全ページの印を新しくする（GitHub Pages は 10 分ほど古いものを配るので、新しい HTML と古い CSS が混ざらないように）
- 訪問の数は Cloudflare Web Analytics で見る（2026-10-24〜。訪れた人の個人の情報は集めない）。DNS は Cloudflare だがプロキシしていない（DNS のみ）ので自動では入らない。全ページの `</body>` の前に Cloudflare の数行（`static.cloudflareinsights.com/beacon.min.js`）を置いている。新しいページにも同じ数行を入れる。数字は Cloudflare のダッシュボードの「Web 分析」→ dsign.art

## 新しい作品を足すとき（TORSO・DRIVER’S SEAT）

1. 原寸の PNG から、タイル（`tiles.dzi`。JPEG 品質 90・色の間引きなし・TileSize 510・Overlap 1）、`whole-*.jpg`、`spot-*.jpg`（原寸の 720 × 900 px をそのまま切る）、`og.jpg` を作る。コンテナで作り、メタデータがないことを確かめる
2. `torso/00N/index.html`（DRIVER’S SEAT は `drivers-seat/00N/index.html`）を 001 にならって作る（寄りの場所は投稿の切り抜きと同じ座標。末尾の Cloudflare の数行も残す）
   - TORSO の「工程」の文は 001 を写さない。その作品で実際にやったことを、前の作品からの変化も含めて書く（道具の名前は書かず、技法の行に書く）。作り方が変わったら、`home.html` の TORSO の段落と `record.html` の TORSO の項も、変わった分を本人の了承で直す
   - DRIVER’S SEAT には工程の文を置かない（作り方そのものが作品の意味になる回が来たら、そのときだけ足す）
   - ビューアの高さ（`.viewer-stage`）は、共通の CSS では TORSO No.001 の縦横比（56.03%）で切ってある。縦横比が違う作品は、作品ページの `<style>` で上書きする（`drivers-seat/001/` は 2:1 なので 50vw）
3. シリーズの一覧（`torso/index.html` か `drivers-seat/index.html`）、`home.html` の作品、`record.html` を足す
4. 扉（`index.html` の `#door-works`。`tx` `ty` は動きが止まる所）に足すか替えるか、ホームの先頭の絵、帯の位置と色（`css/site.css` の `:root`）を新しい作品に替えるかは、本人に聞いてから。DRIVER’S SEAT No.001 は扉に足した（2026-11-09。TORSO と代わる代わる）。ホームの先頭の絵と帯は替えていない（ページの割り付けが縦の帯でできているので、縦の色面のない作品に帯を合わせると全体が組み直しになる）

## 電波のない所で見せる（2026-11-11）

- `offline.html`（どこからもリンクしていない・noindex）を開いて「保存する」を押すと、サイトをまるごと（約 270 MB、原寸のタイルと書体まで）その端末に入れる。保存したあとは、電波がなくても同じアドレス（dsign.art）で見られる。グラスヒュッテのインタビューに iPad で持っていくために作った
- 保存はページ自身が Cache API で行い、`sw.js`（service worker）はつながらないときだけ保存した分を出す。つながるときはいつもどおりネットから読む（3.5 秒で返らなければ保存した分）。`offline.html` を開いた端末でだけ動くので、ほかの人の閲覧には関係しない
- 何を保存するかは `offline-files.json`（ファイルの一覧と大きさ）。ページや作品を足したら作り直す（README・CNAME・.nojekyll・sw.js 自身は除く）。作り直したあと、保存した端末で「もう一度確かめる」を押せば新しい分だけ足される
- iPad では Safari とホーム画面のアプリは保存の場所が別。Safari で保存したら Safari で開く
- 「保存した分を消す」で、保存も service worker も消える
